E-commerce Sales Analysis using SQL

📌 Project Overview

This project analyzes e-commerce sales data using SQL to identify sales trends, customer behavior, product performance, and business insights.

🛠️ Tools Used

* MySQL
* SQL

📂 Dataset

The project contains:

* Customers
* Products
* Orders

📊 Analysis Performed

* Total revenue
* Total orders
* Top customers by spending
* Best-selling products
* Category-wise revenue
* City-wise revenue
* Customer segmentation using CASE
* Ranking using RANK()
* CTE-based analysis
* Running revenue totals

🧠 SQL Concepts Used

* SELECT
* WHERE
* GROUP BY
* HAVING
* ORDER BY
* JOIN
* Aggregate Functions
* CASE
* Subqueries
* CTE
* Window Functions
* RANK()

🎯 Key Learning

This project helped me improve my SQL problem-solving skills and understand how SQL can be used to extract meaningful business insights from raw data.
